下一交易日五項觀察

  1. 加權能否守住 40,000 點附近，並觀察台積電反彈是否延續。
  2. 補核 11/24 上市及上櫃融資，觀察反彈期間兩市餘額變化。
  3. 兩市外資合計賣超是否收斂。
  4. 台灣 VIX 能否維持在 26.18 附近或續降，並核對美東最新 SOX 收盤。
  5. 兩市淨騰落能否維持正值，合計 ADL 是否持續上升。
