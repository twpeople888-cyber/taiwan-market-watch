四階段判斷

第一階段｜市場下跌

指數反彈，廣度轉弱

加權連兩日上漲，11/27 櫃買下跌 1.40%，兩市下跌股票仍多於上漲。

第二階段｜籌碼清理

合計融資下降

上市融資下滑，上櫃小增，兩市合計減少 39.97 億元。

第三階段｜賣壓衰竭

尚待確認

VIX 由高檔回落，兩市淨騰落卻翻負，未延續前一交易日的廣度改善。

第四階段｜資金回流與底部確認

尚未確認

兩市仍淨賣超，市場廣度與加權反彈不同步。

下一交易日五項觀察

11/30 預計開市，台股比較基準採上週五 11/27。

  1. 加權能否守住 11/27 收盤 39,308.08，並觀察櫃買是否跟上。
  2. 上市與上櫃融資是否同向變動，五日背離是否收斂。
  3. 外資賣超能否續縮，台積電是否維持相對強勢。
  4. 台灣 VIX 是否繼續降溫，並觀察 SOX 提前收盤上漲後台股半導體的反應。
  5. 兩市淨騰落能否轉正，合計 ADL 是否回升。
